Helpers¶

Helpers.py¶

Module containing all helper functions for the Desq GUI.

This module provides utility functions for:

  • Dynamic Python module importing with security controls

  • HDF5 file I/O with recursive dictionary serialization

  • PyQt5 widget creation helpers

  • File dialog management with persistent path memory

  • Time/date formatting utilities

JSON encoder that handles NumPy data types.

Extends the standard JSONEncoder to properly serialize NumPy integers, floats, and arrays which are not natively supported by the json module.

Variables:

default (method) – Overridden method that converts NumPy types to native Python types.

Example:

import numpy as np
import json

data = {"array": np.array([1, 2, 3]), "value": np.float64(3.14)}
json_str = json.dumps(data, cls=NpEncoder)
# Result: '{"array": [1, 2, 3], "value": 3.14}'

See also

dict_to_h5() which uses this encoder for config serialization.

Create and configure a QPushButton with standard settings.

Factory function for creating consistently styled buttons throughout the Desq GUI application.

Parameters:

  • text (str) – Display text for the button.

  • name (str) – Object name for the button (used for styling and identification).

  • enabled (bool, optional) – Whether the button starts enabled. Defaults to True.

  • parent (QWidget, optional) – Parent widget for the button. Defaults to None.

  • shadow (bool, optional) – Whether to apply a drop shadow effect. Currently unused - shadow code is commented out. Defaults to True.

  • checkable (bool, optional) – Whether the button can be toggled on/off. Defaults to False.

Returns:

The configured QPushButton instance.

Return type:

QPushButton

Example:

toggle_btn = create_button("Toggle", "toggle_button", checkable=True)
scripts.Helpers.dict_to_h5(data_file: str, dictionary: Dict[str, Any]) → None¶

Store a dictionary to an HDF5 file with recursive structure preservation.

Recursively traverses the dictionary and stores each value using the appropriate HDF5 structure (datasets, groups, or attributes).

Parameters:

  • data_file (str) – Path where the HDF5 file will be created.

  • dictionary (dict) – Dictionary to serialize. Supports nested dicts, lists, NumPy arrays, strings, and numeric types.

Raises:

  • TypeError – If the dictionary contains unsupported data types.

  • OSError – If the file cannot be created.

See also

_recursive_save() for the implementation details. h5_to_dict() for the inverse operation. NpEncoder for JSON encoding of NumPy types in config.

Example:

data = {
    "config": {"param1": 1.0, "param2": "value"},
    "measurements": np.array([1, 2, 3]),
    "nested": {"inner": np.array([4, 5, 6])}
}
dict_to_h5("experiment_data.h5", data)
scripts.Helpers.extract_metadata(h5file: str) → Dict[str, Any]¶

Extract all attributes (metadata) from an HDF5 file’s root.

Reads the top-level attributes of an HDF5 file, which typically contain configuration and experiment metadata stored by dict_to_h5().

Parameters:

h5file (str) – Path to the HDF5 file.

Returns:

Dictionary mapping attribute names to their values. Note that values may be JSON strings that need parsing.

Return type:

dict

Raises:

OSError – If the file cannot be opened.

See also

h5_to_dict() which uses this function internally.

Example:

metadata = extract_metadata("experiment.h5")
config = json.loads(metadata.get("config", "{}"))
scripts.Helpers.format_date_time_pretty(seconds_from_now: float) → str¶

Calculate a future datetime and format it as a readable string.

Adds the specified number of seconds to the current time and returns a formatted date/time string.

Parameters:

seconds_from_now (float) – Number of seconds to add to current time.

Returns:

Formatted string in “MM/DD HH:MMam/pm” format (lowercase am/pm).

Return type:

str

Example:

# If current time is 01/15 2:30pm:
>>> format_date_time_pretty(3600)  # 1 hour from now
'01/15 03:30pm'
>>> format_date_time_pretty(86400)  # 24 hours from now
'01/16 02:30pm'

Format a duration in seconds as a human-readable string.

Converts a floating-point number of seconds into a formatted string showing hours, minutes, seconds, and milliseconds.

Formatted string in the format “XXh XXm XXs XXXms”.

scripts.Helpers.h5_to_dict(h5file: str) → Dict[str, Any]¶

Load an HDF5 file and return its contents as a nested dictionary.

Recursively loads all groups and datasets from the HDF5 file, including metadata stored as attributes. The ‘config’ attribute is automatically parsed from JSON.

Parameters:

h5file (str) – Path to the HDF5 file to load.

Returns:

Dictionary containing all data from the file. The ‘attrs’ key is removed if present (metadata is handled separately).

Return type:

dict

Raises:

  • OSError – If the file cannot be opened.

  • json.JSONDecodeError – If metadata JSON is malformed.

See also

_recursive_load() for the recursive loading implementation. extract_metadata() for extracting file attributes. dict_to_h5() for the inverse operation.

Note

NaN values in numeric arrays are replaced with 0 during loading. This behavior is implemented in _recursive_load().

scripts.Helpers.import_file(full_path_to_module: str, banned_imports: List[str] | None = None) → Tuple[ModuleType, str]¶

Securely import a Python file with static and runtime protection against banned modules.

This function provides a secure way to dynamically import Python modules while blocking specified imports. It uses a two-phase approach:

  1. Static Analysis: Parses the source code using AST to detect direct imports of banned modules and logs warnings.

  2. Runtime Blocking: Installs a custom import hook that intercepts import attempts during module execution, returning dummy modules for banned imports.

Parameters:

  • full_path_to_module (str) – Absolute path to the Python file to import.

  • banned_imports (list of str, optional) – List of module names to block from importing. These are matched against the final component of the module path (e.g., “socProxy” would block “some.package.socProxy”). Defaults to an empty list if None.

Returns:

A tuple containing: - The imported module object - The module name (filename without extension)

Return type:

tuple[ModuleType, str]

Raises:

ImportError – If the module cannot be loaded due to syntax errors, missing file, or other import failures.

Note

The import hook is installed temporarily and removed in a finally block, ensuring cleanup even if an exception occurs.

Note

DEPRECATED CODE: There is a commented-out simpler version of this function (lines 142-163 in original) that lacks the banned import functionality. This was the original implementation before security controls were added.

Warning

This function modifies sys.meta_path temporarily. Concurrent imports from multiple threads may experience unexpected behavior.

See also

BlockImportHook and DummyLoader (nested classes) for implementation details of the import blocking mechanism.

Example:

module, name = import_file("/path/to/experiment.py", banned_imports=["socProxy"])
experiment_class = getattr(module, "MyExperiment")
scripts.Helpers.open_file_dialog(prompt: str, file_args: str, settings_id: str, parent: QWidget | None = None, file: bool = True, initial_dir: str | None = None) → str | None¶

Open a file or directory selection dialog with persistent path memory.

Opens a Qt file dialog and remembers the last used directory for each unique settings_id, restoring it on subsequent calls. This provides a better user experience by starting in familiar locations.

Parameters:

  • prompt (str) – Title text displayed in the dialog window.

  • file_args (str) – File filter string (e.g., “Python Files (.py);;All Files ()”). Ignored when file=False.

  • settings_id (str) – Unique identifier for storing/retrieving the last used directory in QSettings.

  • parent (QWidget, optional) – Parent widget for the dialog. Defaults to None.

  • file (bool, optional) – If True, opens a file selection dialog. If False, opens a directory selection dialog. Defaults to True.

  • initial_dir (str, optional) – Override directory to start in, ignoring saved path. Defaults to None (use saved path).

Returns:

Selected file/directory path, or None if dialog was cancelled.

Return type:

str or None

Note

Uses QSettings with organization “HouckLab” and application “Desq”. Settings are stored in platform-specific locations:

  • Windows: Registry under HKEY_CURRENT_USERSoftwareHouckLabDesq

  • macOS: ~/Library/Preferences/com.houcklab.Desq.plist

  • Linux: ~/.config/HouckLab/Desq.conf

Example:

path = open_file_dialog(
    "Select Experiment File",
    "Python Files (*.py);;All Files (*)",
    "last_experiment_dir"
)
if path:
    print(f"Selected: {path}")
scripts.Helpers.simple_h5_to_dict(h5file: str) → Dict[str, ndarray]¶

Convert an HDF5 file to a dictionary with all datasets loaded as arrays.

This is a simplified loader that assumes all values in the HDF5 file are datasets (no groups) and loads them directly into memory. For more complex HDF5 structures with nested groups, use h5_to_dict() instead.

Parameters:

h5file (str) – Path to the HDF5 file to load.

Returns:

Dictionary mapping dataset names to their data arrays.

Return type:

dict[str, numpy.ndarray]

Raises:

  • OSError – If the file cannot be opened.

  • KeyError – If the file structure is invalid.

See also

h5_to_dict() for recursive loading with group support and metadata.
