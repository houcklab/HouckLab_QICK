VoltagePanel¶

VoltagePanel.py¶

The home of a voltage controller interface panel for Qblox and Yoko hardware.

This module provides a GUI panel for manual voltage control across multiple channels, supporting both Qblox (16-channel DAC) and Yokogawa GS200 (single-channel) voltage sources. The panel allows users to:

  • Select and configure voltage interface hardware

  • Connect/disconnect from hardware with visual feedback

  • Set voltages on individual channels with range validation

  • View current voltage values across all channels

Note

Sweeps functionality and passing a reference of the voltage interface are only supported for ExperimentPlus experiments. The sweeps UI code is currently commented out. Sweeps should instead be done within experiment files

var visa:

PyVISA module for VISA instrument communication (used by Yoko).

See also

VoltageInterface - Base class for voltage hardware interfaces. YOKOGS200 - Yokogawa GS200 driver. QBLOX - Qblox DAC driver.

A custom QWidget class for the voltage control panel.

This panel provides a complete interface for connecting to and controlling voltage source hardware. It supports both Qblox (16-channel DAC) and Yokogawa GS200 (single-channel) instruments.

Variables:

  • yoko_settings (Dict[str, str]) – Default settings for Yokogawa GS200 connection.

  • qblox_settings (Dict[str, Any]) – Default settings for Qblox connection.

  • range_numbers (Dict[int, List[float]]) – Mapping of Qblox range_num to [min, max] voltage limits.

  • connected (bool) – Whether a voltage interface is currently connected.

  • voltage_interface (Optional[VoltageInterface]) – The active voltage interface connection, or None.

  • voltage_hardware (Optional[VoltageInterface]) – The hardware reference passed to experiments (usually same as voltage_interface).

  • range (List[float]) – Current voltage range as [min, max] list.

  • parent (QWidget) – Parent widget reference.

  • config_tree_panel (QConfigTreePanel) – Reference to the configuration tree panel for updating config values via the UI.

  • current_tab (QQuarkTab) – Reference to the current experiment tab.

  • main_layout (QVBoxLayout) – The main vertical layout containing all components.

  • interface_connect_layout (QVBoxLayout) – Layout for connection controls.

  • voltage_interface_combo (QComboBox) – Dropdown to select voltage interface type.

  • voltage_interface_currtype (str) – Currently selected interface type string.

  • voltage_interface_settings (QTextEdit) – Text editor for JSON connection settings.

  • create_connection_button (QPushButton) – Button to create/delete connection.

  • controller_content (QWidget) – Widget containing channel controls.

  • controller_layout (QVBoxLayout) – Layout for controller content.

  • voltage_channels_group (QGroupBox) – Group box containing channel controls.

  • voltage_channels_layout (QVBoxLayout) – Layout inside the channels group box.

  • voltage_range_label (QLabel) – Label showing current voltage range.

  • channel_scroll_area (QScrollArea) – Scroll area for channel list.

  • channel_list (QWidget) – Widget containing channel layouts.

  • channel_list_layout (QVBoxLayout) – Layout for channel list.

  • qblox_channel_list (QWidget) – Widget containing Qblox channel controls.

  • qblox_channel_list_layout (QVBoxLayout) – Layout for Qblox channels.

  • yoko_channel_list (QWidget) – Widget containing Yoko channel control.

  • yoko_channel_list_layout (QVBoxLayout) – Layout for Yoko channel.

  • is_connecting (bool) – Flag indicating connection attempt in progress.

  • connecting_dot_count (int) – Counter for connection animation dots.

  • aux_thread (QThread) – Background thread for connection operations.

  • aux_worker (AuxiliaryThread) – Worker object running in aux_thread.

Note

The sweeps functionality (sweeps_group, sweeps_layout) is currently commented out in the implementation. This appears to be planned functionality for voltage sweep operations.

create_connection() → bool | None¶

Create a new connection to the selected voltage interface.

Parses the settings from the text editor, validates the JSON format, and starts a background thread to initialize the hardware connection.

Returns:

False if JSON parsing fails, None otherwise (result comes via signal from background thread).

Return type:

Optional[bool]

Raises:

json.JSONDecodeError – Caught internally - shows error dialog.

Note

The actual connection happens in a background thread via AuxiliaryThread. Success/failure is communicated via signals to successful_interface_connection() or failed_connection_error().

delete_connection() → None¶

Delete the connection to the voltage interface.

Deletes the voltage_interface variable and sets the reference to None. This allows Python’s garbage collector to clean up the hardware connection resources.

failed_connection_error(e: str, timeout: bool = False) → None¶

Handle a failed connection error from the auxiliary thread.

Shows an error dialog and resets the connection button to allow retry attempts.

Parameters:

  • e (str) – Error message describing the failure.

  • timeout (bool) – Whether the failure was due to a timeout.

handle_voltInterface_change(index: int) → None¶

Handle when the user changes the voltage interface type.

Switches between Qblox and Yoko channel displays and updates the settings text field with appropriate defaults.

index (int) – The index of the selection made in the combo box. Not used directly - the current text is read from the combo box.

qblox_settings: Dict[str, Any] = {'COM_speed': 1000000.0, 'module': 2, 'num_dacs': 16, 'port': 'COM3', 'ramp_interval': 0.05, 'ramp_step': 0.003, 'range_num': 2, 'reset_voltages': False, 'timeout': 1}¶

Default Qblox connection settings. Modify this dictionary to change default values.

Note

The range_num parameter determines the voltage range:

  • 0: 0 to 4V (unipolar)

  • 2: -4 to 4V (bipolar, default)

  • 4: -2 to 2V (bipolar)

range_numbers: Dict[int, List[float]] = {0: [0, 4], 2: [-4, 4], 4: [-2, 2]}¶

Mapping of Qblox range_num values to [min, max] voltage ranges.

  • 0: range_4V_uni (span 0) → [0, 4]

  • 2: range_4V_bi (span 2) → [-4, 4] (default)

  • 4: range_2V_bi (span 4) → [-2, 2]

set_voltage(channel: int, voltage_input: QLineEdit, set_button: Any) → None¶

Set voltage on the specified channel of the connected interface.

Validates the voltage against the current range before setting. Provides visual feedback via the Set button text during operation.

Parameters:

  • voltage_input (QLineEdit) – The QLineEdit containing the voltage value.

setup_signals() → None¶

Set up all the signals and slots of the Voltage Panel.

Connects:

  • voltage_interface_combo.currentIndexChanged → handle_voltInterface_change

  • create_connection_button.clicked → toggle_create_connection

Also disables the voltage channels group until a connection is made.

setup_voltage_channels() → None¶

Set up the UI for the voltage channels for both Qblox and Yoko.

Creates 16 channel rows for Qblox (channels 1-16) and 1 channel row for Yoko. Each row contains a label, voltage input field, and Set button.

Note

The lambda capture pattern with default arguments lambda _, ch=i, input_box=channel_voltage_input, ... is used to avoid the late binding issue where all lambdas would otherwise reference the final loop value.

Note

Channel numbers displayed to user are 1-indexed, but the internal channel parameter passed to set_voltage is 0-indexed (ch-1).

setup_voltage_interface_settings() → None¶

Set up the voltage interface settings with default values.

Populates the settings text editor with JSON-formatted default settings for either Yoko or Qblox based on current selection.

Note

The JSON formatting removes the outer braces and adds them back when parsing, which allows users to edit just the inner content. This is a somewhat fragile approach.

successful_interface_connection(voltage_interface: VoltageInterface) → None¶

Handle a successful voltage interface connection.

Saves the connected interface, updates the UI to show connection status, and refreshes the channel voltage displays.

Parameters:

voltage_interface (VoltageInterface) – The successfully connected voltage interface.

toggle_create_connection() → None¶

Toggle the create connection button between create and delete modes.

Ensures we are not creating multiple instances of voltage interfaces. When creating, starts the connection animation and initiates the connection in a background thread. When deleting, disconnects and re-enables the UI for a new connection.

update_voltage_channels() → None¶

Update the voltage channel displays with current hardware values.

Retrieves all current voltages from the connected voltage interface and updates the placeholder text of each channel’s input field.

Default Yokogawa GS200 VISA connection settings. Modify this dictionary to change default values.
