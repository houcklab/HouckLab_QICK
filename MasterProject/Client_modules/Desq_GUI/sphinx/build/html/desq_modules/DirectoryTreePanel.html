DirectoryTreePanel¶

DirectoryTreePanel.py¶

This module provides a directory tree panel component for navigable file system views within the Desq GUI application.

The module contains two main classes:

  • FilteredFileSystemModel: A custom QFileSystemModel that displays all files but disables selection of files that don’t match specified filters.

  • DirectoryTreePanel: A panel widget that displays an interactive directory tree view with file filtering capabilities.

class scripts.DirectoryTreePanel.DirectoryTreePanel(parent: QWidget | None = None, file_filters: List[str] | None = None, history_key: str | None = None, workspace: str | None = None)¶

Bases: QWidget

A panel widget that displays an interactive directory tree view.

This panel provides a file browser interface using QFileSystemModel with support for file filtering, directory selection, and persistent directory history via QSettings.

Variables:

  • load_file (pyqtSignal(str)) – Signal emitted when a file is double-clicked (full path).

  • file_selected (pyqtSignal(str)) – Signal emitted when a file is single-clicked (full path).

  • file_filters (List[str]) – List of enabled file extensions (e.g., ['.py', '.h5']).

  • history_key (Optional[str]) – QSettings key for persisting the last selected directory.

  • workspace (str) – Base workspace directory path.

  • default_folder_name (Optional[str]) – Default subfolder name within the Data directory.

  • layout (QVBoxLayout) – Main vertical layout for the panel.

  • toolbar_layout (QHBoxLayout) – Horizontal layout for the toolbar area.

  • load_directory_button (QPushButton) – Button to open directory selection dialog.

  • tree_view (QTreeView) – The tree view widget displaying the directory structure.

  • model (FilteredFileSystemModel) – The filtered file system model backing the tree view.

  • settings (QSettings) – QSettings instance for persisting user preferences.

Note

The panel automatically creates a “Data” subdirectory in the workspace if it doesn’t exist, and optionally creates an experiment-specific subfolder based on the parent widget’s name.

__init__(parent: QWidget | None = None, file_filters: List[str] | None = None, history_key: str | None = None, workspace: str | None = None) → None¶

Initialize the DirectoryTreePanel.

Parameters:

  • parent (Optional[QWidget]) – The parent widget. If the parent has a name attribute, it will be used as the default folder name within the Data directory.

  • file_filters (Optional[List[str]]) – List of file extensions to enable for selection (e.g., ['.py', '.h5', '.json']). Defaults to common experiment and image file types if not provided.

  • history_key (Optional[str]) – QSettings key for persisting the selected directory. If None, the panel assumes it’s a config selector and uses the Data directory instead of saved history.

  • workspace (Optional[str]) – Base workspace directory path. Defaults to the parent directory of the module’s location.

Note

When history_key is None, the panel operates in “config selector” mode, creating and navigating to a Data subdirectory within the workspace rather than restoring a previously saved directory.

refresh_view() → None¶

Refresh the directory view to show any new or modified files.

Forces the model to reload the current directory by temporarily resetting the root path. This is useful after file operations that may have changed the directory contents.

Note

This is a workaround to force QFileSystemModel to refresh its cache. The model’s built-in file watching may not always detect changes immediately.

class scripts.DirectoryTreePanel.FilteredFileSystemModel(parent: QWidget | None = None, file_filters: List[str] | None = None)¶

Bases: QFileSystemModel

Custom QFileSystemModel that shows all files but disables those that don’t match the specified file filters.

This model extends QFileSystemModel to provide visual filtering of files based on their extensions. Files that don’t match the filter appear grayed out and cannot be selected, while directories remain navigable regardless of filters.

Variables:

file_filters (List[str]) – List of file extensions that should remain enabled (e.g., ['.py', '.h5']).

Note

Files that don’t match the filter are still visible but appear grayed out and cannot be selected. This provides better context than hiding files entirely.

data(index, role: int = 0)¶

Override data to style disabled items with a gray foreground color.

This method intercepts the Qt.ForegroundRole to return a gray color for files that don’t match the filter, providing visual feedback that these files are not selectable.

Parameters:

  • index (QModelIndex) – The model index to get data for.

  • role (int) – The data role to retrieve (default: Qt.DisplayRole).

Returns:

The data for the given index and role. Returns a gray QColor for non-matching files when role is Qt.ForegroundRole.

Return type:

Any

Note

The gray color (RGB 128, 128, 128) is hardcoded. Consider making this configurable for theme compatibility.

Override flags to disable files that don’t match the file filters.

Directories remain enabled for navigation regardless of filter settings. Files that match the filter retain default flags, while non-matching files are completely disabled (no selection, no interaction).

Parameters:

The item flags for the given index.

Note
