MockExperimentsAdv¶

MockExperimentAdvanced.py - Advanced mock experiments for testing GUI figure handling

These experiments focus on testing the GUI’s ability to handle: 1. Figures with different grid configurations (1x1, 1x2, 2x2, 2x3, 3x3, GridSpec layouts) 2. Experiments that create multiple separate figures 3. Experiments with live plotting (updating during sweeps/loops) 4. Experiments with multiple figures where some are live-updating

Unlike MockExperiments.py which tests plot appearance, this module tests the backend’s ability to properly route, update, and manage complex figure scenarios.
