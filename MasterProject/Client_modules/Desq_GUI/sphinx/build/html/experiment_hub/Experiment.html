Experiment¶

Experiment Module¶

This module provides base classes for managing quantum experiments, including data file handling, configuration management, and experiment workflow orchestration.

The module contains:

  • MakeFile: HDF5 file wrapper for experimental data storage

  • NpEncoder: JSON encoder with NumPy type support

  • ExperimentClass: Base class for all experiment implementations

Note

This module requires the MasterProject.Client_modules.Desq_GUI.scripts.Helpers module for HDF5 dictionary serialization utilities.

class CoreLib.Experiment.ExperimentClass(path: str = '', outerFolder: str = '', prefix: str = 'data', soc: Any | None = None, soccfg: Any | None = None, cfg: Dict[str, Any] | None = None, config_file: str | None = None, liveplot_enabled: bool = False, short_directory_names: bool = False, **kwargs: Any)¶

Bases: object

Base class for all quantum experiments.

Provides infrastructure for experiment execution including:

  • Automatic directory creation and file path management

  • Configuration file handling (JSON format)

  • HDF5 data file management

  • Standard experiment workflow (acquire -> analyze -> save -> display)

Variables:

  • path (str) – Subdirectory name for experiment data

  • outerFolder (str) – Base directory for all experiment data

  • prefix (str) – Suffix used when creating data files

  • cfg (Optional[dict]) – Experiment configuration dictionary

  • soc (Optional[Any]) – QICK system-on-chip instance for hardware control

  • soccfg (Optional[Any]) – QICK system-on-chip configuration

  • config_file (Optional[str]) – Path to configuration file (JSON)

  • dname (str) – Base path for data files (without extension)

  • fname (str) – Full path to HDF5 data file (.h5)

  • iname (str) – Full path to image file (.png)

  • cname (str) – Full path to configuration file (.json)

Note

The load_config method and associated functionality (InstrumentManager, LivePlotter, dataserver_client) have been commented out in the original implementation and are not currently functional.

See also

MakeFile for HDF5 file handling NpEncoder for configuration JSON serialization

__init__(path: str = '', outerFolder: str = '', prefix: str = 'data', soc: Any | None = None, soccfg: Any | None = None, cfg: Dict[str, Any] | None = None, config_file: str | None = None, liveplot_enabled: bool = False, short_directory_names: bool = False, **kwargs: Any) → None¶

Initialize the experiment class with file paths and configuration.

Creates the necessary directory structure for data storage and sets up file paths for data (.h5), images (.png), and configuration (.json).

Parameters:

  • path (str) – Subdirectory name for experiment data within outerFolder

  • outerFolder (str) – Base directory path for all experiment data

  • prefix (str) – Suffix to use when creating data files (despite the name, this is actually used as a suffix in filenames)

  • soc (Optional[Any]) – QICK system-on-chip instance for hardware control

  • soccfg (Optional[Any]) – QICK system-on-chip configuration object

  • cfg (Optional[Dict[str, Any]]) – Experiment configuration dictionary

  • config_file (Optional[str]) – Path to configuration file. If relative path (no leading /), it is joined with the path parameter. If None, no config file is loaded.

  • liveplot_enabled (bool) – Whether to enable live plotting (currently unused)

  • short_directory_names (bool) – If True, use simplified directory naming (date only). If False, include path prefix in directory names.

  • kwargs (Any) – Additional keyword arguments are added to instance __dict__

Note

The prefix parameter name is misleading - it is actually used as a suffix in the generated filenames (e.g., datetime_prefix.h5). This is old code so it is kept for backwards compatibility.

classmethod export_data(data_file: str, data: Dict[str, Any], config: Dict[str, Any]) → None¶

Export experiment data to an HDF5 file.

Exports a dictionary with potentially nested data into an HDF5 file. Supports hierarchical storage for nested dictionaries and direct key-value pairs.

Parameters:

  • data_file (str) – Path to the HDF5 file to create

  • data (Dict[str, Any]) – Dictionary containing experiment data, may be nested

  • config (Dict[str, Any]) – Configuration dictionary (currently unused in implementation)

Note

The config parameter is accepted but not used in the current implementation. Only data is exported via Helpers.dict_to_h5().

See also

Helpers.dict_to_h5() for the underlying serialization

go(save: bool = False, analyze: bool = False, display: bool = False, progress: bool = False) → None¶

Execute the full experiment workflow.

Runs the experiment through its standard phases: acquire data, optionally analyze, optionally save, and optionally display results.

Parameters:

  • save (bool) – If True, save data after acquisition/analysis

  • analyze (bool) – If True, run analysis on acquired data

  • display (bool) – If True, display results after processing

  • progress (bool) – If True, show progress during acquisition

Note

The workflow order is fixed: acquire -> analyze -> save -> display. Each step passes its data to the next enabled step.

add(key: str, data: Any) → None¶

Add or update a dataset in the HDF5 file.

Creates a new dataset with the given key, or replaces an existing one if a dataset with that key already exists. The dataset is created with unlimited dimensions (resizable) and float64 dtype.

Parameters:

  • key (str) – The name/path of the dataset in the HDF5 file

  • data (Any) – The data to store, will be converted to numpy array

Raises:

RuntimeError – Caught internally when dataset already exists, triggers deletion and recreation

Note

The dataset is always stored as float64 regardless of input dtype. The maxshape is set to (None, ...) allowing unlimited growth in all dimensions.

class CoreLib.Experiment.NpEncoder(*, skipkeys=False, ensure_ascii=True, check_circular=True, allow_nan=True, sort_keys=False, indent=None, separators=None, default=None)¶

Bases: JSONEncoder

JSON encoder that handles NumPy data types.

Extends json.JSONEncoder to properly serialize NumPy integers, floats, and arrays to their Python equivalents for JSON compatibility.

Note

This encoder converts:

  • np.integer types to Python int

  • np.floating types to Python float

  • np.ndarray to Python list

See also

json.JSONEncoder for base class documentation
